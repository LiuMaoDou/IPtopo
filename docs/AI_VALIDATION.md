# AI 对话验证记录

当前平台范围（2026-10-28 后续调整）：全部功能仅面向 PC 桌面浏览器；手机和平板不属于当前开发、维护与验收范围。下文初版的手机检查保留为历史记录。

本记录针对 2026-10-28 的本地开发版本。使用独立临时数据目录和六设备四厂商合成项目验证；没有将现有真实项目发送给模型。接入步骤见 [AI 使用说明](AI.md)。

## 功能和事实来源

- 应用内对话共用 9 个只读工具，支持设备、接口、逻辑组网、配置路径、LSDB 路径、配置与观测对比、有限脱敏来源片段。
- 原生 Codex / OpenCode 与 API 工具循环共用确定性查询引擎；外部 Agent 通过带临时令牌的 MCP 使用相同查询。
- 查询绑定项目事实版本；画布位置保存不会改变事实版本。配置或观测变化后，新问题使用新上下文，历史卡片停用画布动作。
- 项目数据和来源属于不可信输入。工具只返回限定范围的数据；不向模型开放 Shell、文件修改、任意 SQL 或其他项目。

## 自动化和浏览器检查

执行以下命令可复现代码检查：

```sh
.venv/bin/python -m pytest backend/tests -q
PYTHONPATH=. .venv/bin/python scripts/validate_public_network.py
cd frontend
npm test
npm run build
```

最终结果：后端 **647 项通过**，前端 **19 项通过**，TypeScript 与生产构建通过，公开厂商资料样例 **123 项校验通过**。后端仅有既存 Starlette TestClient 的 httpx 弃用警告。

## 同期代码审查修复

| 原问题 | 修复与回归 |
| --- | --- |
| 替换导入读取失败可能删除此前有效设备 | 输入失败时保留未成功替换的旧文件，并报告失败 |
| 较旧详细 LSDB 覆盖较新摘要或撤销记录 | 先比较序列和新旧，再判断是否有可用详细正文；不复活过期连接 |
| 配置窄度量上限影响独立观测路径 | 观测 SPF 不再继承配置路径开销上限 |
| 应用能导出却无法恢复较大项目备份 | 导出、恢复共用独立限额，默认 256 MiB；实际约 68 MiB 往返与历史原文校验通过 |
| 手工链路缺少地址族，路径引擎忽略它 | 根据两端地址推导共同地址族；仍由引擎核实协议和地址条件 |
| 解析子进程异常退出后项目一直锁定 | 下一次 HTTP 回收死进程、标记 interrupted、清理 staging，旧快照保持完整且可重新导入 |
| 分页标记被清洗后无法报告截断配置 | 清洗前检测并保留诊断 |
| Windows 打包只带最初 demo | 打包完整 samples 目录；未在本机生成或验证 Windows EXE |

备份仍在内存中处理 JSON，恢复限额可用 `IPTOPO_MAX_RESTORE_BYTES` 调整；这不是无限容量或流式备份。
